# Contributing — OKKAZ Backend

Quelques règles rapides pour contribuer :

- Branche feature depuis `dev` et ouvrez une PR vers `dev`.
- Respectez les règles ESLint et TypeScript strict.
- Écrivez des tests unitaires pour la logique métier importante.
- Ajoutez une entrée dans `CHANGELOG.md` pour les changements significatifs.

Contact: équipe backend / mainteneur du dépôt.
