    • webhookSignature(
          headerName?: string,
      ): (req: Request, _res: Response, next: NextFunction) => void

      Factory de middleware qui vérifie la signature HMAC-SHA256 d'un webhook.

      Flux :

      1. Récupère le raw body depuis req.rawBody (capturé par le middleware bodyParser avec l'option verify).
      2. Récupère la signature du header x-webhook-signature.
      3. Calcule le HMAC attendu avec WEBHOOK_SECRET.
      4. Compare les deux signatures avec crypto.timingSafeEqual().
      5. Si mismatch → 401 Unauthorized (log warning).

      Parameters

      • headerName: string = "x-webhook-signature"

        Nom du header HTTP contenant la signature (défaut : 'x-webhook-signature').

      Returns (req: Request, _res: Response, next: NextFunction) => void

      Middleware Express vérifiant la signature.

      Example

      router.post('/payments/webhook', webhookSignature(), asyncHandler(controller.webhook));

      Throws

      401 si la signature est absente ou ne correspond pas.
