    Module utils/apiResponse

    Description

    Fonctions utilitaires pour envoyer des réponses HTTP standardisées au format JSON. Chaque réponse respecte la structure :

    {
      "success": true | false,
      "message": "...",
      "data": { ... },
      "meta": { ... }          // (optionnel, pagination)
      "error": { "code": ... } // (optionnel, en cas d'échec)
    }
